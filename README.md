# PedagokIT — offre IFEC 2027 (lots G131, G133, G137)

Ce dépôt aide chaque formateur de l'ASBL PedagokIT à rédiger **sa fiche de formation** pour
l'appel d'offres IFEC 2027, avec Claude Code.

**À remettre au plus tard le 25/11/2026, par mail à info@pedagokit.be : votre fiche `.md` + votre CV.**

## Démarrer (une seule fois)

1. Récupérer le dossier sur votre ordinateur :
   ```bash
   git clone https://github.com/jpbolle/pedagokit-ifec-2027.git
   ```
2. Ouvrir ce dossier dans Claude Code.
3. Taper `/fiche-ifec` : Claude vous guide, une question à la fois.

## Récupérer les mises à jour du harnais

```bash
git pull
```

## Bon à savoir

- Vous ne poussez **rien** sur GitHub : votre fiche part **par mail**.
- Les règles suivies par Claude sont dans `AGENTS.md` ; les attentes de l'IFEC dans `harnais/`.
